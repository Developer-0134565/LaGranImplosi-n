# Engine modules

The authoritative game engine lives in Supabase PostgreSQL.

Core domains: economy, construction, research, shipyard, defense, fleet movement/fuel/cargo, combat, expeditions, lifeforms, universe evolution/clock/expansion, AI population, and guest onboarding.

This directory is reserved for versioned backend SQL/source snapshots. Do not put React presentation code here.

As of 2026-09-15 the live database is authoritative, while the repository is being brought into sync with it.
