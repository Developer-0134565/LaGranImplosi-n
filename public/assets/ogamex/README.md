# OGameX visual reference assets

This directory is a local visual reference pack for the LGI UI prototype.

- Source: `lanedirt/OGameX`
- Pinned source revision: `7c420bad3478d7099791e1f33c920e9ff92822e8`
- Source paths: `public/img/objects/{buildings,research,units}`
- Import script: `npm run assets:ogamex`
- The UI resolves these files from `/assets/ogamex/objects/**`.

**Rights note:** OGameX's repository source code is MIT, but its README explicitly says OGame artwork/rights belong to GameForge GmbH. These images are therefore marked as **reference-only** in LGI and should be replaced or relicensed before public/commercial distribution.
